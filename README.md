# えふいーさん 🦉

**基本情報技術者試験（FE）対策アプリ**。インストール不要で、ブラウザで開けばすぐ使えます。スマホではホーム画面に追加してオフラインでも使えます（PWA）。

## 収録内容

| 種類 | 内容 |
| --- | --- |
| 科目A | オリジナル問題 171問（15分野・テクノロジ／マネジメント／ストラテジ） |
| 科目B | 擬似言語のアルゴリズム問題 16問＋情報セキュリティ 4問 |
| 計算ドリル | 基数変換・2の補数・稼働率・MTBF・実効アクセス時間・MIPS・伝送時間・サブネット・損益分岐点・鍵の数など 12種（毎回数値が変わる） |
| 用語カード | 106語（用語→意味／意味→用語の両方向） |

## 効果を高める仕組み

1. **間隔反復**：正解した問題は 1日 → 3日 → 1週間…と間隔を広げて再出題。試験日を設定すると、試験前に必ず復習できるよう間隔を調整します。
2. **確信度評価**：正解後に「自信あり／迷った／勘」を選択。勘で当たった問題は未習得として翌日に再出題します。
3. **その場で解き直し**：間違えた問題はセッションの最後にもう一度出題します。
4. **交互学習**：同じ分野が続かないよう並べ替えて出題します。
5. **弱点×配点の重点化**：本番での出題数が多く、習熟度が低い分野から優先して新しい問題を出します。
6. **模擬試験**：科目A（60問・90分）、ミニ模試（30問・45分）、科目B（20問・100分）。見直しフラグと問題一覧つき。

## 使い方

```bash
# 任意のHTTPサーバで配信（例）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` を直接開いても動作します（オフラインキャッシュはHTTP配信時のみ有効）。GitHub Pages でそのまま公開できます。

学習記録はブラウザの localStorage に保存されます。端末を移るときは「設定 → バックアップを保存／復元」を使ってください。

## 開発

- ビルド不要の素のHTML/CSS/JavaScript
- `js/data-a.js`（科目A）、`js/data-b.js`（科目B）、`js/data-terms.js`（用語）、`js/drills.js`（計算ドリル）、`js/app.js`（本体）
- データの整合性チェック：`node tests/validate.js`

> 収録問題はすべてオリジナルです。試験制度の最新情報は IPA（情報処理推進機構）の公式サイトで確認してください。
